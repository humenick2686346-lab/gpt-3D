# 樱梦浮岛 · 富士花境 V3.1.0

这是经过构建和断网浏览器检查的固定交付快照。

- `sakura-dream-offline.html`：独立单文件，优先在 Windows Chrome / Edge 中双击打开。
- `sakura-dream-offline.zip`：独立网页、离线说明、许可证与 `start-local.cmd`。
- `sakura-dream-complete.zip`：完整源码和离线版本。
- `sakura-dream-source.zip`：可编辑项目源码。
- `THIRD_PARTY_LICENSES.txt`：第三方依赖许可证原文。

离线包不依赖 CDN、远程字体、模型、纹理或实时网络 API。云端已在禁用网络的 Chromium 中验证场景、昼夜、雨雪、镜头与再次下载；实际 Windows 双击和启动器仍需 Windows 实机确认。
