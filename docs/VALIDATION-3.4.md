# V3.4.0 验证记录

验证环境：Linux、Chromium 和 SwiftShader 软件 WebGL，2026-10-29。

- `npm test`：7 项核心测试通过，覆盖两岛尺寸、浦东地标、U 型竹桥两端和弯曲范围、富士山与岛体以及三处水道和瀑布的连续衔接。
- TypeScript 检查与 `npm run build` 通过，生成在线版、独立 HTML、离线 ZIP 和源码包。
- 900 × 600 真实 WebGL 浏览器加载并渲染双岛、浦东地标、U 型竹桥及流动云层；检查 10:30 和 22:00 的昼夜画面，场景报告两座岛、一条跨岛桥和四处上海地标，控制台及 JavaScript 错误为零。暂停昼夜时水与落樱动画时间继续增长。截图检查后调整了桌面默认构图，避免右侧面板遮挡浦东岛。
- 对桌面 1600 × 1000 和手机 390 × 844 的英雄、正面、俯视及侧面视角进行投影检查，双岛、地标和桥均在画面内。
- 本环境软件渲染约 0.1–0.2 FPS，不能代表真实显卡表现；Windows 上的双击启动和 GPU 性能尚未实测。离线包沿用自包含构建流程，本版尚未完成 Windows 实机验证。

上一版验证记录见 [V3.3](VALIDATION-3.3.md) 和 [V3.2](VALIDATION.md)。
