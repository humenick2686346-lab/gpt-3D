# V3.1.0 验证记录

验证日期：2026-10-19。浏览器：Chromium 154.0.8037.57；环境：云端 Linux、SwiftShader 软件 WebGL。

## 已通过

- `npm test`：4 项核心测试通过，0 失败。
- `npm run build`：TypeScript 类型检查、标准网站、自包含 HTML、离线 ZIP、源码 ZIP、完整交付 ZIP全部生成。
- `npm run test:browser`：11 组端到端检查通过，0 个 JavaScript、Shader 或控制台错误。
- 浏览器实际渲染确认 9 座建筑、29 棵樱花树、2 座桥、2 座鸟居、3 条瀑布和中画质约 11,000 株实例花卉。
- 英雄镜头投影检查确认岛屿左右边缘、前后边缘、富士山顶和岩石底端均位于可视区域。
- 昼夜检查包括正午、午夜、24:00 端点、夜间灯笼和自动播放跨午夜。
- 天气检查包括夜雨、日间雪、强度调整、湿润 / 积雪材质状态，以及天气与时间相互独立。
- 相机检查包括正面、俯视、侧面、复位、鼠标旋转、滚轮缩放、右键平移与慢速环绕。
- 离线检查在完全禁网的浏览器上下文中运行同一个单文件 HTML，完成昼夜、雨、雪、侧面镜头和下载往返，网络请求列表为空。
- 强制丢失 WebGL 上下文后显示可读错误提示，没有持续黑屏。

原始机器报告见 [validation.json](validation.json)。测试截图包括英雄、正面、俯视、侧面、夜景、雨夜、雪景和离线版本；仓库预览图来自通过检查的英雄镜头。

## 性能采样

| 测试视口与档位 | FPS | 自适应像素比 | 绘制调用 | 三角形 |
| --- | ---: | ---: | ---: | ---: |
| 1920 × 1080、低画质、SwiftShader | 0.7 | 0.65 | 42 | 1,590,708 |

这是无 GPU 的软件渲染瞬时采样，不是 Windows 独立显卡基准。本环境没有达到 60 FPS，项目也不作固定帧率承诺。低绘制调用说明实例化与材质合批有效；三角形主要来自 6,500 株可辨识花卉、樱花花瓣簇和完整建筑细节。真实中等独立显卡仍需以 1920 × 1080 实机测试。

## 尚未验证

- 云端 Chromium 的组织策略禁止直接导航到 `file://`。测试使用全禁网 `about:blank` 加载完全相同的独立 HTML；没有绕过管理策略。实际 Windows Chrome / Edge 双击打开需要实机确认。
- `start-local.cmd` 的 PowerShell 本地服务逻辑已检查并随离线包交付，但当前 Linux 环境不能执行 Windows 批处理文件。
- GitHub Pages 工作流已准备；当前环境访问 GitHub Pages/API 会被网络代理拒绝，因此没有把候选 URL 宣称为已上线地址。
- 阴影、水流、湿润与积雪均为实时艺术化表现，不是物理模拟或离线电影级路径追踪。
