## 验证方法与边界

云端没有硬件 GPU。SwiftShader 的慢帧会使 Playwright 的按钮稳定帧等待超过超时，因此固定按钮先断言可见、可用，再通过 DOM click 触发其事件；全屏保留真实用户手势点击，旋转、缩放和平移保留实际鼠标输入。自动环绕按实际相机变化等待，不使用固定毫秒延迟。

完整功能验证分阶段执行：前七组成功后，修正了软件慢帧下的环绕等待，再续跑环绕与后续检查。机器报告保留 `resumedAfterSlowFrameWait` 说明。离线截图专项另外发现自适应分辨率在绘制之后调整会清空完成帧；本版将调整移到本帧绘制之前，调整后立即绘制，并单独核对修复后的禁网渲染。英雄预览复用同一最终几何的已审阅截图；随后仅调整雨滴数值安全、自适应计时与绘制顺序。

截图通过 Chromium CDP 获取，并校验 PNG 尺寸与当前视口一致。主要截图输出在 `test-results/`；仓库的 [preview.webp](preview.webp) 为本版英雄镜头。

低画质不捕获实时平面倒影；中、高画质共享一个反射纹理，并跳过微小花卉实例与雨雪粒子的倒影绘制。水面、瀑布、湿润与积雪均为实时程序化表现，不是物理流体模拟。

软件渲染采样不能代表 Windows 独立显卡帧率。当前 Linux 环境也不能验证 Windows 双击与 `start-local.cmd` 的实际执行。浏览器若阻止 `file://`，会在完全禁网的 `about:blank` 中运行同一份独立 HTML；机器报告记录该限制。

补充禁网专项实际观测分辨率从 1 降至 .65，调整前后完整场景均可见，网络请求数与 JavaScript / Shader 错误数均为 0；没有暂停动画或强制 GPU 同步。最终打包只同步源码归档与验证文档，并核对运行脚本及样式与专项验证版本相同。

原始机器报告见 [validation.json](validation.json)。
